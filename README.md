# EQUINOX – The Cosmic Daily

A space exploration and astronomy portal delivering telemetry data, planetary information, deep-space news, and cosmic audio ambiance.

## Live Demo
Check out the live interactive portal on GitHub Pages:
**[https://saanviiiivn.github.io/EQUINOX/](https://saanviiiivn.github.io/EQUINOX/)**

---

## Features
- **Cinematic Hero**: Ultra-high-resolution orbital Earth curved horizon with dynamic Ken Burns animation and canvas starfield particle generator.
- **Planetary Observatory**: Quick telemetry cards for Earth (Terra), Mars (Ares), and Jupiter with orbital distance, gravity, and mission specs.
- **Deep Space Chronicles**: News dispatches featuring James Webb Space Telescope discoveries, NEO asteroid radar surveillance, and millisecond pulsars.
- **Interactive Astro Physics Quiz**: Live interactive multiple-choice quiz with immediate scientific feedback.
- **Sagittarius A* Gravity Simulator**: Kerr-metric black hole event horizon visualizer.
- **Cosmic Ambiance Synthesizer**: In-browser dual-oscillator binaural drone generator (55Hz / 110Hz) powered by the Web Audio API.
- **Dual-Mode Theme**: Seamless Dark and Light theme switcher with persistent local storage.
- **Global Search Modal**: Quick search filtering across planetary, telescope, and celestial catalog entries.
